# XUI Browser Client

VPN-клиент только для браузера для серверов панели [3x-ui](https://github.com/MHSanaei/3x-ui)
(Xray: VLESS, в том числе Reality, VMess, Trojan, Shadowsocks). Пока только Firefox.
Неофициальный; не связан с 3x-ui и Project X.

## Как устроено

Браузер сам не умеет протоколы Xray, поэтому частей две:

- **Помощник** (`native-host/`, Go, без зависимостей) — native messaging host. Хранит ссылки
  серверов на этом компьютере, собирает конфиг Xray и запускает `xray-core`, который открывает
  SOCKS5 на `127.0.0.1` со случайным паролем на каждый запуск.
- **Расширение** (`extension/`, MV3) — направляет трафик Firefox в этот SOCKS5 через
  `proxy.onRequest`. Имена сайтов разрешаются на стороне сервера.

Через VPN идёт только трафик браузера.

### Лёгкий режим (без помощника, ставится только расширение)

Inbound 3x-ui типа **HTTP** с **TLS** — это обычный HTTPS-прокси (HTTP CONNECT поверх TLS с логином и
паролем), с ним Firefox работает сам. Добавляется в настройках: «Добавить сервер „HTTPS-прокси“» (или
вставьте `https://логин:пароль@хост:порт`). Серверу нужны домен с доверенным сертификатом и ALPN `http/1.1`.
Через прокси Cloudflare такой сервер **не работает** (Cloudflare не пропускает CONNECT); для CDN нужен VLESS
поверх XHTTP / WebSocket + TLS, а ему нужен помощник. Если серверу нужен помощник, а его нет, расширение
об этом скажет и подскажет, как установить.

## Возможности

- Импорт ссылок `vless://`, `vmess://`, `trojan://`, `ss://` (одной или нескольких) и адреса
  подписки (`https://…/sub/…`, список в base64); обновление подписки одной кнопкой.
- Транспорты: TCP/RAW, WebSocket, gRPC, HTTPUpgrade, XHTTP, mKCP; защита: none, TLS, Reality.
- Где работает VPN: во всех вкладках, только в отмеченных вкладках и контейнерах или только в приватных окнах.
- Раздельное туннелирование по спискам сайтов и по стране сайта.
- Kill switch, защита от утечки через WebRTC, «Проверить IP» с VPN и без, счётчики трафика.
- Интерфейс на английском и русском.

## Установка (macOS, Linux)

Нужен Go 1.22+. `xray` берётся из `XRAY_BIN`, иначе из `PATH` (например, `brew install xray`),
иначе собирается из исходников Xray-core (нужен `git`).

```bash
./scripts/install.sh
```

Затем перезапустите Firefox и загрузите расширение: `about:debugging` → «Этот Firefox» →
«Загрузить временное дополнение» → `extension/manifest.json` (или установите подписанный `.xpi`).
В настройках расширения вставьте ссылку сервера или адрес подписки, выберите сервер и включите VPN
в окне расширения.

Удаление помощника: `./scripts/uninstall.sh` (`--purge` удаляет и сохранённые серверы).

## Установка (Windows)

Архив собирает `./scripts/build-windows.sh` (на macOS/Linux, нужен Go) → `dist/xui-browser-client-<версия>-windows.zip`.
На Windows распакуйте его и запустите `install.cmd` (права администратора не нужны): он копирует помощник, скачивает
официальный релиз `xray-core` с GitHub со сверкой SHA-256 и регистрирует помощник в Firefox. Затем установите `.xpi`.
Обычный Firefox ставит только подписанный `.xpi` (`scripts/sign.sh`); неподписанный загружается временно через `about:debugging`.

## Данные

- Ссылки серверов с ключами (права 600): macOS `~/Library/Application Support/XUI-Browser/profiles`,
  Linux `~/.config/xui-browser/profiles`.
- Журнал Xray: `…/logs/xray.log`.
- Настройки и списки сайтов — в профиле Firefox (`storage.local`), ключей там нет.

Адрес подписки помощник запрашивает напрямую, не через VPN.
